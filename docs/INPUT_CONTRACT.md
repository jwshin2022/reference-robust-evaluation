# Input contract

Score CSV columns are case, reference, score_a, score_b. Scores are finite decimal or rational strings in [0,1]. A case/reference key occurs once. The margin is nonnegative; superiority uses strict inequalities, and equality at the margin is unresolved.

Compiled JSON has a and b model objects with identical positive integer domains and a common positive area_weight_denominator. Integer numerator/denominator units are stored as integer strings. Components within each model form disjoint scopes; omitted variables have invariant contributions. Each option table includes every mixed-radix assignment (the first listed variable is the least-significant digit). Lower/upper assignment fields are feasible seed choices, not trusted optimality certificates.

The joint component graph combines both models' scopes. Denominator differences must be constant over each joint component. Every attainable paired denominator must be positive. The verifier recomputes witness scores and rejects missing, overlapping or invalid prefix covers. Input SHA-256 binds CLI certificates to exact JSON bytes.

Geometry accepts a Cartesian product of coherent ROI alternatives composed by Boolean union. Choosing alternative 0 in different ROIs does not imply a common reader. Cross-region choice constraints and arbitrary affine geometry are outside this release. Resource refusal preserves that contract and never replaces the full choice space with a sample.
